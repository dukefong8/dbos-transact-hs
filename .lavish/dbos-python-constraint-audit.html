How to read the tables

Every constraint row carries its enforcement class and verdict; every citation is to the working tree or an oracle file.

Enforcement classes

CT compile-time — the state is unrepresentable or the only entry point has the required shape (phantom brands, view-typed APIs, sum types, absence of a workflow-less signature).
RT runtime — refused on a matchable ADT channel (ErrorConfig, InvalidArgument, InsideStep, InvalidInput) with a test pinning the refusal.
N/A not expressible or not applicable in Haskell (event-loop rules, async-step parameters) or a documented discipline where no oracle enforces (determinism, globals).

B1
over-refusal		 validateQueueOptions refuses a partition_rate_limit whose cross-multiplied window exceeds the queue-wide rate_limit ("must not exceed rate_limit"). Both oracles accept that shape: a shorter per-partition window merely caps bursts the queue-wide window allows.
