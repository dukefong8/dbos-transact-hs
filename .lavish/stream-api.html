Goal and current state

Deliver durable stream parity and the recorded-name update

The SystemDB already has stream data types and notifier key support. The Postgres stream methods remain deferred stubs; the Postgres stream tests are compiled but not included in the active group. There is no app-facing stream reader yet.

Rust adds a pull reader, a client stream, paged SystemDB reads, waits, and broad changes to recorded internal step names. Haskell’s port should keep the oracle’s behavior while preserving its own explicit WorkflowCtx and m (Either Error a) conventions.

Replay compatibility needs a decision. Step names are persisted and checked on replay. Changing DBOS.readStream to DBOS.read_stream can make an existing recorded operation fail its name check. The same concern applies to the other renamed operations.

Agreed public surface

Export all three from DBOS.Transact

StreamReader toVectorStream foldVectorStream

toVectorStream maps DBOS read errors into an error-carrying monad so they cannot look like normal end-of-stream. foldVectorStream consumes the vector stream with Foldl.FoldM. No M suffix.

The reader should remain opaque and execution-scoped. The vector fusion stream and fold adapter make the chosen interop part of the public contract; tests should verify errors propagate and end-of-stream remains distinct.

Behavior to cover

Acceptance checklist

  • SystemDB stream behaviorWrite/close idempotence, computed offsets and collision behavior, sentinel handling, paged reads, missing workflow, status with empty pages, limit validation, and all-entry listing.
  • Workflow readerReplay returns first-run values and end position; offset advances correctly; timeout, cancellation, terminal producer, serialization failure, and close sentinel behave like the oracle.
  • WakeupsProve the supported local notifier wake path. Retain polling correctness; document cross-process listener limitations if Rust behavior cannot be mirrored under the existing Haskell backend decision.
  • AdaptersVector Skip does not call the fold step; Yield calls it once; Done extracts once; stream errors propagate instead of becoming EOF.
  • Name changeEvery changed constant matches commit #94, literal assertions pin the intended spelling, and no old step-name literal remains where the oracle changed it. SQL/wire data that Rust did not change remains untouched.
Decision recorded

Adopt snake_case in this port slice

Port the #94 recorded-name spelling changes with the stream work. No compatibility alias for old names is planned. A workflow replaying history written under the prior spelling may fail its operation-name check; keep this risk visible in the dated port-plan delta and user-facing change notes.
