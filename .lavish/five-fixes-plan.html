3 · Bracket acquireConnection's activate

src/DBOS/Internal/DBOS/Transact/Connection.hs:152–153

Problem. Acquire-then-activate with no bracket: if activatePostgresSystemDB throws, the pool is never released. The client path already does it right with bracketOnError (Client.hs:180). Same latent shape in Backend.hs:1036 (Pool.acquire then fromPool).

Solution. Mirror the client: bracketOnError acquire release activate-then-build in acquireConnection; same wrap for acquire/fromPool.

5 · Make shutdown exception-safe

src/DBOS/Internal/DBOS/Transact/Instance.hs:219–223

Problem. If releaseConnection (:219) throws, the EngineShutdown trace, releaseTracer, and both thaws are skipped — registries stay frozen, logger leaks.

Solution. Bracket the close: trace + release + thaws in the release/finally arm so they run regardless. Same review for double-activate (Backend.hs:1062 swapMVar orphans the first flush task).
